🔍 SEO Testing Checklist

Use this page to test your portfolio's SEO. Open your portfolio in another tab and run these tests.

1. Quick Visual Checks

✅ View Page Source

Right-click → "View Page Source" and check:

  • Meta description is present and descriptive
  • Title tag is optimized (50-60 characters)
  • Structured data (JSON-LD) is present
  • Canonical URL is set

2. Browser DevTools Testing

✅ Chrome Lighthouse Audit
  1. Open your portfolio in Chrome
  2. Press F12 to open DevTools
  3. Go to "Lighthouse" tab
  4. Select "SEO" checkbox
  5. Click "Analyze page load"
  6. Target: Score 90+

What to check:

  • ✅ Document has a meta description
  • ✅ Document has a valid hreflang
  • ✅ Links are crawlable
  • ✅ Image elements have [alt] attributes
  • ✅ Page has successful HTTP status code

5. Manual Checklist

Meta Tags ✅

Title tag is optimized (50-60 chars)
Meta description is present (150-160 chars)
Keywords meta tag included
Open Graph tags present
Twitter Card tags present
Canonical URL set

Structured Data ✅

Person schema present
WebSite schema present
ProfessionalService schema present

Content ✅

One H1 tag per page
Proper heading hierarchy (H1 → H2 → H3)
All images have alt text
Semantic HTML used (section, header, main, footer)

Technical ✅

Sitemap.xml exists and is valid
Robots.txt exists and is valid
Mobile-responsive design
Page loads quickly (< 3 seconds)
